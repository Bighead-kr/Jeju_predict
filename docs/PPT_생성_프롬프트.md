## 프롬프트 전문

```
당신은 전문 프레젠테이션 디자이너입니다.
아래 [디자인 시스템]과 [슬라이드 구성안]에 따라 발표용 PPT(또는 슬라이드덱)를 제작해 주세요.

## [디자인 시스템]

이 발표 자료는 실제 운영 중인 AI 관제 플랫폼의 UI 디자인을 그대로 계승합니다.
아래 규칙을 슬라이드 전체에 일관되게 적용하세요.

### 색상 팔레트
- 배경(Canvas): #f5f5f5 (따뜻한 오프화이트) — 모든 슬라이드 기본 배경
- 잉크(Ink Primary): #292524 (따뜻한 근-블랙) — 타이틀, 강조 텍스트
- 본문(Body): #4e4e4e — 일반 설명 텍스트
- 뮤트(Muted): #777169 — 캡션, 서브레이블
- 카드 표면(Surface Card): #ffffff — 내용 카드 배경
- 구분선(Hairline): #e7e5e4 — 카드 테두리, 섹션 구분선
- 강조(Surface Strong): #f0efed — 뱃지, 칩 배경
- 다크 반전(Surface Dark): #0c0a09 — 핵심 강조 슬라이드 배경 (스파링 사용)
- 액센트 없음: 채도 높은 원색 CTA 컬러를 사용하지 마세요.

### 대기 그라디언트 오브 (시각적 분위기 연출)
슬라이드 배경 모서리나 후면에 아래 색상의 부드러운 방사형 그라디언트 원을 흐릿하게(blur 80~120px, opacity 10~15%) 배치하여 감성적인 깊이감을 표현하세요.
다만 텍스트나 카드 위에 올라가지 않도록 순수 장식 요소로만 사용합니다.
- 민트 오브: #a7e5d3
- 피치 오브: #f4c5a8
- 라벤더 오브: #c8b8e0
- 스카이 오브: #a8c8e8
- 로즈 오브: #e8b8c4

### 타이포그래피
- 슬라이드 타이틀(Display): EB Garamond 또는 Georgia, weight 300 (라이트 세리프) — 에디토리얼 매거진 질감
- 본문/설명: Inter 또는 Apple SD Gothic Neo, weight 400–500
- 한국어 본문: Noto Sans KR, weight 400–500
- 뱃지/레이블: 소문자 추적자(letter-spacing 0.08em) Inter weight 600, 소형 캡션 처리
- 타이틀에 bold 처리 금지 — weight 300~400의 가는 서체가 이 디자인의 핵심

### 컴포넌트 스타일
- 카드: 흰 배경(#ffffff), 1px #e7e5e4 테두리, border-radius 12~16px, 극미한 그림자(0 4px 16px rgba(0,0,0,0.03))
- 버튼/뱃지 형태: 완전한 pill 형태(border-radius 9999px)
- 강조 뱃지: #f0efed 배경 + #292524 텍스트 + pill 형태
- 다이어그램 노드: 흰 카드 위에 얇은 테두리 — 색 면 채움 최소화
- 신뢰도 표시: ✅ 초록(#16a34a) / ⚠️ 앰버(#d97706) / 🔴 레드(#dc2626)

### 슬라이드 레이아웃 원칙
- 1슬라이드 1메시지: 한 화면에 하나의 핵심 내용만
- 여백을 넉넉히: 96px 이상의 섹션 여백, 인쇄 잡지 같은 호흡
- 텍스트 과적 금지: 슬라이드당 본문 3~5줄 이내
- 수치/결과는 크게: 핵심 숫자(MAE, MW, 정확도)는 display 크기로 전면 배치
- 다크 슬라이드는 최대 2장: 오프닝 또는 임팩트 포인트에만 #0c0a09 배경 사용
```
